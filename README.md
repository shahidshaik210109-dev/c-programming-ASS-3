## How to Compile and Run

**Step 1:** Install GCC compiler.

**Step 2:** Open the terminal in the project folder.

**Step 3:** Compile the program:

```bash
gcc -std=c11 -Wall -Wextra Q1.c -o Q1
```

**Step 4:** Execute the program:

```bash
./Q1
```

For Windows:

```bash
Q1.exe
```

Replace `Q1.c` and `Q1` with the required question's filename.
